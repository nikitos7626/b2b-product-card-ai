# B2B Product Card AI Assistant · AI-помощник подготовки карточек товаров КИПиА

Промышленный сервис для автоматической генерации и валидации черновиков карточек товаров контрольно-измерительных приборов и автоматики (КИПиА) для B2B интернет-магазина с детерминированной защитой от галлюцинаций.

**Репозиторий проекта:** [https://github.com/nikitos7626/b2b-product-card-ai](https://github.com/nikitos7626/b2b-product-card-ai)

---

## 1. 🚀 Инструкция по установке и запуску

### Шаг 1. Клонирование репозитория и настройка окружения
```bash
git clone https://github.com/nikitos7626/b2b-product-card-ai.git
cd b2b-product-card-ai
cp .env.example .env
```
В файле `.env` укажите ваш API-ключ Google Gemini:
```ini
GEMINI_API_KEY=ваш_ключ_google_ai_studio
```
*(Модель `gemini-flash-lite-latest` и порт `8000` зашиты в дефолтные параметры приложения, дополнительных настроек не требуется).*

---

### Шаг 2. Запуск сервиса

#### Вариант А: Запуск через Docker (Рекомендуемый)
```bash
docker compose up --build
```
Сервис автоматически соберет контейнер и поднимется на `http://localhost:8000`.

#### Вариант Б: Локальный запуск на Python
```bash
pip install -r requirements.txt
python -m app.main
```
- **Интерактивный веб-интерфейс:** `http://localhost:8000`
- **Документация Swagger OpenAPI:** `http://localhost:8000/docs`
- **Проверка здоровья (Health-check):** `http://localhost:8000/api/health`

#### Запуск модульных тестов:
```bash
pytest tests/ -v
```
*(11 изолированных тестов, время выполнения ~0.35 с).*

## 3. 🧠 Описание промптов и принятых инженерных решений

1. **Разделение ответственности (Код vs Промпт):**
   - Промпт освобожден от рутины форматирования: вся нормализация чисел и единиц измерения по ГОСТ (`0–1,6 МПа`, `M20×1,5`, `4...20 мА`, `100 мм`, `°C`) выполняется детерминированным Python-модулем ([app/validator.py](app/validator.py)).
   - Модели поручены задачи языкового синтеза: профессиональный B2B-текст без «воды» и клише, семантическое ядро (3–5 поисковых запросов) и коммерческий блок для менеджеров по продажам.
2. **Защита от галлюцинаций (Zero Hallucination Grounding):**
   - Значения параметров берутся только из входных данных; отсутствующие поля помечаются как `"данных нет"`.
   - Программный `Grounding Verifier` сличает числовые факты из ответа LLM с исходным паспортом изделия и маркирует неподтвержденные данные.
3. **Таксономия и аудит полноты данных (238 категорий):**
   - В систему встроена спарсенная база из 238 категорий приборов КИПиА (`souz-pribor.ru`) с обязательными атрибутами для каждой категории.
   - При отсутствии критически важных полей (резьба, класс точности, диапазон) система формирует замечание контент-менеджеру.
4. **Слоистая архитектура (MVC) и Concurrency:**
   - Эндпоинты вынесены в слой контроллеров ([app/controllers/](app/controllers/)), а [app/main.py](app/main.py) выполняет роль тонкой фабрики `create_app()`.
   - Обработчики используют синхронные функции `def`, делегируемые FastAPI в пул потоков Starlette (`run_in_threadpool`), что гарантирует свободный асинхронный Event Loop.
5. **SEO & Schema.org Product:**
   - Карточка генерирует валидную микроразметку JSON-LD (`@type: Product`, `additionalProperty`), готовую для формирования расширенных сниппетов (Rich Snippets) в поисковиках.

## 4. ⚠️ Список ограничений решения и возможных улучшений

### Текущие ограничения MVP:
1. **Отсутствие постоянного хранилища (БД):** сервис работает на лету и не сохраняет историю запросов в СУБД (согласно условиям тестового задания).
2. **Синхронный конвейер:** генерация выполняется в рамках одного HTTP-запроса (для пакетной обработки тысяч приборов требуется очередь задач).
3. **Локальный веб-интерфейс:** выполнен в виде SPA без авторизации пользователей и ролевого доступа.

### Возможности для масштабирования в Production (Roadmap):
1. **Гибридный пайплайн с экстрактором GLiNER:** использование легковесной спановой модели GLiNER для мгновенного (20–40 мс) извлечения технических сущностей без риска галлюцинаций, с вызовом LLM только для синтеза текста (экономия до 70% токенов).
2. **Фоновая очередь задач (Celery / Redis):** пакетная обработка файлов Excel/CSV на 10 000+ позиций в асинхронном режиме.
3. **Экспорт в CMS:** прямая выгрузка сгенерированных карточек через API в 1C-Битрикс, OpenCart или маркетплейсы.
4. **OCR паспортов приборов:** автоматическое распознавание PDF/сканов паспортов и свидетельств об утверждении типа СИ.
